Privacy policy

Last updated: 5 October 2026

Short version: AgentDeck collects nothing. Everything stays on your computer.

What AgentDeck does with your data

  • No telemetry, no analytics, no accounts. AgentDeck never sends anything to its author or to any server.
  • What it reads, locally: the session files and logs of Claude Code and Codex on your computer, and the permission requests those agents send it through their hooks. It does not read their login credentials.
  • What it stores, locally in %APPDATA%\AgentDeck: your rules, settings, usage numbers, and an audit log of approval requests (kept 90 days). Uninstalling with Delete the application data ticked removes all of it.
  • Network: the only network use is the optional CI status feature. When you turn it on, AgentDeck asks your GitHub CLI (gh) for the status of your repository's GitHub Actions after an agent pushes. That request goes from your computer to GitHub under your own GitHub account, as if you ran gh yourself. It is off by default.

When you send feedback

Send feedback opens a GitHub issue page in your browser. Whatever you write or attach there (such as a diagnostic bundle) is shared under GitHub's privacy statement. The diagnostic bundle is created only when you click Export, saved to your Downloads folder so you can look at it first, and contains versions, settings and counts: no commands, code, prompts or file paths. Your user name and computer name are removed.

This website

No cookies, no analytics, and no third-party requests: fonts and images are served from this site.

Changes

If this ever changes (for example, an optional update check), it will be listed here and in the changelog, and it will be off until you turn it on.

Contact

Use Send feedback in the app, or open an issue.
