03Safety net

Approvals that resist rubber-stamping.

Every request gets a risk level (low, medium, high or critical) with the reason in plain words. Risky ones slow you down just enough to think.

Try itType a command an agent might ask to run

  • LOW Allow, Always or Deny in one click
  • MEDIUM Same, and "Always" rules apply
  • HIGH Hold Allow for 0.8 s. Rules skip it unless you opt in
  • CRITICAL Hold Allow for 1.5 s. Only ever allowed once

A simplified version of AgentDeck's classifier, running in your browser. The real one understands bash, PowerShell and cmd: quoting, chained commands, $(…), aliases, wrappers and encoded PowerShell.

Buttons ignore clicks for 400 ms after a card appears, so a click meant for another window can't approve anything.

If it's not running, nothing changes

Closed, crashed or slow: your agents simply ask in their terminal as always. AgentDeck never approves anything on its own when something goes wrong.

Agents can't approve themselves

The answering key lives only in memory. The hook key on disk can only ask, never answer.

Built-in speed bumps

Force-pushes, rm -rf and reading key files are denied unless you turn the speed bumps off in Rules.

Rules with limits

"Always" rules never approve a high-risk request unless that rule opts in. Critical requests can only be allowed once.

Honest note: risk badges are a warning, not a sandbox. AgentDeck only sees what an agent asks permission for, and a determined trick can get past a text check. Keep your agent's own permission settings sensible.

04Privacy

Everything stays
on your PC.

No telemetry. No analytics. No accounts. AgentDeck makes no network calls of its own.

Reads, locally

The session files and logs of Claude Code and Codex, and the permission requests they send through their hooks.

Never their login credentials.

Stores, locally

Your rules, settings, usage numbers and the audit log (kept 90 days), all in one folder:

%APPDATA%\AgentDeck
Sends

Nothing.

The one exception is opt-in: CI status asks your GitHub CLI about your own repo after an agent pushes. Off by default.

This website too: no cookies, no analytics, no third-party requests.

06FAQ

Questions, answered.

Something else? Use Send feedback in the app.

Is AgentDeck free?

Yes, it's free to use while in beta. It isn't open source; the license agreement is shown by the installer.

Which agents does it work with?

Claude Code and Codex, on Windows 10 and 11. Seeing sessions needs no setup; answering requests from the island needs the hooks the setup guide adds.

Why does Windows say "Windows protected your PC"?

The beta isn't code-signed yet. Click More info → Run anyway. It installs for your user only, with no admin rights.

What happens if AgentDeck crashes or I quit it?

Nothing changes for your agents: they ask in their terminal as they always do. AgentDeck never approves anything on its own when something goes wrong, and a request nobody answers within 9 minutes goes back to the terminal.

Does it send my code or prompts anywhere?

No. There's no telemetry, no analytics and no account. The only network use is the optional CI status, which asks your own GitHub CLI (gh) after an agent pushes. It's off until you turn it on.

Does it change my agents' settings?

Only to add its own hooks (and, if you want, a status line for Claude's usage meter), with a backup saved first. If you already have your own status line, AgentDeck leaves it alone. Uninstalling removes only AgentDeck's entries; your own settings are left exactly as they were.

Why don't I see Claude usage numbers?

Claude only shares usage through a status line, in terminal sessions, on Pro and Max plans. Turn on the usage meter in Setup.

What if an agent update changes its file format?

AgentDeck checks the format of everything it reads. If an update changes something, only that feature turns off, with a plain message. No guessed numbers.

Downloading in Microsoft Edge? It may warn you. Here's how to keep the file.
  1. In Downloads, hover the file, click ⋯ → Keep (Conserver).
  2. Edge asks again: click the small ⌄ arrow on the right of Delete (Supprimer), then Keep anyway (Conserver quand même). Careful: clicking the word itself deletes the file.
  3. Open it. If Windows says it protected your PC: More info → Run anyway (Informations complémentaires → Exécuter quand même).

Why: the beta isn't code-signed yet and is new, so Windows doesn't know it. Updates from inside the app skip all of this.
